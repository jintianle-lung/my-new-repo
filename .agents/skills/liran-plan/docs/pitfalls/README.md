# 长期避坑知识库

本目录记录 `liran-plan` 仓库长期维护中已经踩过、验证过或从证据中可合理推断的坑。它服务于后续开发、修复、测试、部署和排障，避免重复犯同类错误。

## 读取规则

- 开始任何开发、修复、测试、部署、排障或文档结构调整前，先读项目根目录 `AGENTS.md`。
- 再读本文件，并按下面索引读取相关避坑文件。
- 当前无法判断模块时，默认读取 [general.md](general.md)。

## 写入规则

- 新坑必须在任务收尾前写回本目录。
- 任务中断时，尽量记录已发现但尚未完全提炼的坑，并标注“信息不全，待人工补充”。
- 条目必须基于 git 历史、项目文件、当前对话上下文或实际验证结果。
- 信息不足时，标注“信息不全，待人工补充”或“以下为基于现有证据的推测”。
- 禁止写入密钥、token、账号密码、隐私数据、生产配置全文或完整敏感日志。
- 不要把具体坑细节写进 `AGENTS.md`；`AGENTS.md` 只保留规则和索引。

## 历史回填规则

- 本次历史回填已于 2026-07-07 建立知识库时完成。
- 之后只做增量追加，不重复大规模回填，除非用户明确要求重新审计历史。
- 回填来源包括 git commit message/diff 摘要、项目文档、当前对话上下文和实际验证结果。

## 条目格式

每条坑使用 Markdown 二级标题，并包含：

- 现象
- 根因
- 正确做法
- 验证方式
- 禁止事项
- 相关文件或命令
- 适用范围

## 文件索引

- [general.md](general.md)：单版本仓库结构、安装接线、UI 流程、Stitch 承接与完整视觉复修、完整执行提示词长度与结构门禁、运行时流程合同与编码解锁、QA 与真机清单校验等通用避坑。
