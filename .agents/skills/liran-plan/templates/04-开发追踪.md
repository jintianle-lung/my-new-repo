## 状态迁移规则
1. `待开发 → 进行中`：开始开发或修复。
2. `进行中 → 内部测试通过`：内部验证通过，达到可进入实测的节点。
3. Codex 真机分支：`内部测试通过 → 待实测 → 真机测试通过 → 待用户检查 → 待归档确认 → 归档中 → 已归档 → 已完成`。
4. 用户自己测试分支：`内部测试通过 → 待用户验收 → 用户验收通过 → 待用户检查 → 待归档确认 → 归档中 → 已归档 → 已完成`。
5. 用户选择自己测试后，不得在没有用户明确反馈通过时直接标记 `已完成`。
6. 验收通过后先回写结果并等待用户检查；收到“归档”后，才更新长期事实并创建、验证归档，再按任务 ID 移走本任务活动记录。
7. 归档失败时保留原记录并进入 `归档受阻`，不得标记完成。
8. 任意阶段 → `受阻`：存在真实阻塞原因。
