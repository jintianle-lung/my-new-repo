四档自适应流程

轻量流程（0–35）
独立小 Bug、局部样式、小逻辑。一次简短整理、一次确认、一条轻量 /goal。
标准流程（36–69）
单模块多个文件、单页面或简单多模块业务链。一次模块级整理、一次确认、一条标准 /goal。
深度流程（70–89）
复杂多模块、共享逻辑、新页面复杂状态或高风险任务。非 UI 2 次，UI 3 次 /goal。
完整流程候选（90–100）
