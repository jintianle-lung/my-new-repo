- 年龄范围：2–17 岁。
- 内容覆盖：学前儿童及小学六个年级。
- 用户要求的默认起点：不认字、不会读、不会说、不会写。
- 项目以现有 GitHub 游戏为研究基础，遵循仓库内 liran-plan 流程。

## 工作解释与候选方案（待确认）

- 将默认能力起点解释为产品入口不能要求识字、阅读、口语回答或书写；这不是对所有 ADHD 用户能力的医学判断。
- 候选入口采用可重播的动作示范、图形选择和非口语回应；不能假定图标、图片或语音指令一定能被理解，需确认实际支持需求。
- 候选分层将年龄呈现、学段内容和当前能力分别考虑，不把 2 岁和 17 岁用户放入同一种表现形式，也不自动按年龄推断学习能力。
- 现有七个小游戏暂作为研究对象；保留、修改、新增和删除均未确认。

## 还没有确认的内容

- 首轮主要目标：识字读写入门、注意与任务参与、基础理解与表达支持，或其他目标；不得自动扩大成诊断或治疗产品。
- 是否由家长、老师或其他成人陪同；不同年龄及能力起点是否采用不同陪同方式。
- 不会说的具体含义及可接受回应方式；是否能理解简单口头指令、辨认图片或模仿动作。不得从口语表达能力推断理解能力。
- 是否能够独立点击、拖动或画线，是否存在需要支持的听觉、视觉或动作操作限制。
- 13–17 岁是否只覆盖基础能力与小学内容，还是也需要初高中内容。
- 年级内容依据、设备、单次使用时长、提示与奖励方式、验收责任和可用测试环境。
