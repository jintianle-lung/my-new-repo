## 用户与范围

| 编号 | 项目 | 内容 | 来源 |
|---|---|---|---|
| REQ-001 | 目标用户 | ADHD 用户，2–17 岁，覆盖学前及小学一至六年级 | XQ-001、2、3 |
| REQ-002 | 默认起点 | 默认用户不认字、不会读、不会说、不会写；入门路径不得以这四项能力为前提 | XQ-004 |
| REQ-003 | 多通道 | 支持不只依赖文字的多种输入与回应（听、看、点、拖、描），每项核心任务有主通道与替代通道 | XQ-020、YS-004 |
| REQ-004 | 展示形式 | 需求、问题、实施、验收采用台账呈现，编号固定 | XQ-011 |

## 功能需求

| 编号 | 模块 | 需求内容 | 来源 |
|---|---|---|---|
| REQ-010 | 拼音与发音 | 语音部分重点练习拼音和发音；提供听音、辨音、跟读或非口语选择，不强制开口 | XQ-021 |
| REQ-011 | 声音轨道 | 设计从起点到终点的声音轨道，明确节点、播放顺序、前进条件、重播与反馈 | XQ-022 |
| REQ-012 | 声调滑梯 | 将滑梯与四声轨迹、声音变化、视觉反馈对应，支持声调训练 | XQ-023 |
| REQ-013 | 音字结合 | 拼音、发音、声调结合具体汉字，定义音、字、图的出现顺序及提示撤除 | XQ-024 |
| REQ-014 | 一字多朋友 | 以一个字为中心连接多个词语、图像或场景，以“水”为首个示例 | XQ-025 |
| REQ-015 | 字义与关联词 | 讲解字义，分别呈现相关词与相近词，并设置错误干扰项 | XQ-026 |
| REQ-016 | 字的切切乐 | 汉字按部件、结构或笔画切分并重组；切法以内容审核为准 | XQ-027 |
| REQ-017 | 图像分割 | 图像拆分、辨认与拼合，明确对象、块数、轮廓提示、重组目标 | XQ-028 |
| REQ-018 | 运笔与绕行 | 沿轨迹运笔、形状描画、绕过图形；定义边界、碰撞、方向提示、手部容错 | XQ-029 |
| REQ-019 | 格子定位 | 把对象拖放到正确格子；定义目标格、吸附范围、误放反馈、难度递进 | XQ-030 |
| REQ-020 | 现有七个游戏 | 作为基础逐项审查，保留、修改、删除在审查后决定，不默认全部保留 | XQ-009 |

## 验收标准

| 编号 | 关联 | 验收内容 |
|---|---|---|
| AC-001 | REQ-002 | 入门路径不要求读字、说话、输入文字或书写 |
| AC-002 | REQ-003、010 | 每项核心任务说明主通道、替代通道，以及声音不可用或不发声时的完成路径 |
| AC-003 | REQ-011、012 | 轨道与滑梯有起点、终点、前进条件、重播和反馈规则 |
| AC-004 | REQ-014、015、016 | 字义、组词、相关词、相近词、部件和笔画分别标注关系并经内容审查 |
| AC-005 | REQ-017、018、019 | 定义命中范围、吸附、撤销、重试和误触保护 |
| AC-006 | REQ-010至020 | 每个选定游戏说明训练目标、提示、允许回应和判定规则 |
| AC-007 | 全部 | 在目标使用情境的浏览器中实测；未实测不标通过 |

## 边界

| 编号 | 内容 |
|---|---|
| BJ-001 | 默认不新增儿童账号、个人资料或真实训练记录采集 |
